# 💡 HOW TO USE THESE

1. Gehe zu deinem Plugin-Repository auf GitHub
2. Klicke auf "Releases" 
3. Klicke auf "Create a new release"
4. Fülle folgende Felder:
   - **Tag version:** v1.0.0
   - **Release title:** Copy den "RELEASE TITLE" Text
   - **Release notes:** Copy den kompletten "RELEASE NOTES" Text (alles zwischen den ``` Marken)
5. Klicke "Publish release"

**Das gleiche für alle 5 Plugins wiederholen!** ✅
